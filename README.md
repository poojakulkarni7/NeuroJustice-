# NeuroJustice – AI Legal Assistant

## Description
NeuroJustice is an AI-based legal ethics analysis system developed using Python. It analyzes legal and ethical scenarios and generates structured outputs.

## Technologies Used
- Python
- Tkinter
- SQLite
- PDF Processing Libraries

## Features
- Legal ethics analysis
- Rule-based logic system
- Database integration using SQLite
- Case history storage
- PDF report generation

## Project Structure
- main.py – Main application file
- database.py – Database operations
- ai_model.py – Analysis logic
- report_generator.py – Report generation

## Future Improvements
- Advanced AI integration
- Better UI design
- More legal case categories
